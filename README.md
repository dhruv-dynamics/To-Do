# 📝 Modern Dark To-Do App

A clean, responsive, and modern To-Do web application with a sleek **Cyber-Glass Dark Theme**, built using vanilla **HTML5, CSS3, and JavaScript**.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

---

## ✨ Features

- 🌌 **Modern Cyber-Glass Dark UI:** Clean glassmorphism backdrop blur, neon accents, and smooth gradient highlights.
- 📱 **Fully Responsive:** Adapts seamlessly across desktop, tablet, and mobile screens.
- 💾 **LocalStorage Persistence:** Tasks remain saved automatically even after closing or refreshing the browser.
- 🎯 **Filter Tasks:** Easily switch between **All**, **Pending**, and **Completed** tasks.
- ⚡ **Interactive Actions:** Add tasks, toggle completion with a checkbox, delete individual tasks, or clear all completed tasks with one click.
- 📊 **Dynamic Counters:** Live stats tracking total tasks and remaining pending count.

## 🛠️ Tech Stack

- **HTML5:** Semantic markup
- **CSS3:** Flexbox, CSS Grid, Glassmorphism backdrop-filter, linear/radial gradients
- **JavaScript (ES6):** DOM Manipulation, Array methods (`filter`, `map`, `forEach`), LocalStorage API
